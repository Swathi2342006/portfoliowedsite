# Swathi's Career Growth — Portfolio

## Files
- `index.html` — portfolio sections and content
- `style.css` — responsive dark/neon styling based on the supplied portfolio
- `script.js` — mobile navigation, rotating role title, and email contact form
- `profile.png` — add your own profile photo using this exact filename
- `resume.pdf` — add your resume PDF using this exact filename

## Run locally
1. Extract the ZIP file.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Add your profile photo as `profile.png` and resume as `resume.pdf`.
4. Double-click `index.html` to preview, or open the folder in VS Code and use Live Server.

## Publish on GitHub Pages
Upload all files to a GitHub repository. Go to **Settings → Pages**, select the branch (usually `main`) and folder `/ (root)`, then save.

## Before publishing
- Check that the email and phone number shown in `index.html` are the contact details you want public.
- Replace the education/training details if any dates or percentages need correction.
- The contact form opens the visitor's email app; it does not store or send messages through a server.
- This portfolio lists AWS services in the context of your project/training. Keep only services and skills you can confidently explain in an interview.
